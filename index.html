Bit Counting · Codewars ↗

Моё решение: подсчёт единиц в двоичной записи неотрицательного целого числа.

              
                                function countBits(n) {
                  const binary = n.toString(2);
                  let count = 0;

                  for (let i = 0; i < binary.length; i++) {
                    if (binary[i] === '1') {
                      count++;
                    }
                  }

                  return count;
                }

Например, countBits(7) возвращает 3: двоичная запись числа 7 — 111.
